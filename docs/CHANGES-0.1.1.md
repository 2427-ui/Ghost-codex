# Ghost Studio 0.1.1

2026-10-23

- 默认字号 14 → 16，侧栏、输入框、设置和辅助文本同步放大；中央 GHOST 字标尺寸不变。
- 旧默认字号一次性迁移，用户设置的其他字号不覆盖。
- 原矩形迷你窗替换为透明眼球桌宠，无系统背景和系统阴影。
- 桌宠支持拖动、状态气泡、最新回复摘要、停止任务、点击眼球恢复完整工作台。
- 对话按钮或右键眼球展开输入与消息；支持 Enter 发送、Shift+Enter 换行、会话选择及真实流式回复。
- 展开收起保持眼球锚点，透明区域允许鼠标穿透；恢复主窗口后对话连续。
- 本次没有接入原生 Codex 历史列表，也没有取消项目选择限制。

验证：10 项后端自动化测试，以及真实 Electron 中的字号、透明像素、眼球形态、桌宠真实消息、恢复主窗口与重启恢复验收。
