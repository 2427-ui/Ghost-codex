# 0.2.0 — 直接使用 Codex 原生接口

日期：2026-10-23。

本机稳定协议 105 个请求、完整协议 172 个请求。除握手、测试和内部交互计数 4 项外，其余 168 个请求均提供入口；[完整清单](CODEX-INTERFACES.md)将接入和真实验证分开标注。

- 标题栏“功能”进入功能中心；分类搜索、参数说明、可选项/枚举/数组/对象表单、分页、结果和事件记录。
- 会话重命名、分叉、归档/恢复、删除、历史回退/压缩、全文搜索打开会话；原生项目管理与 canonical projectId。
- 输入区切换执行/Plan、添加图片/音频/文件/显式技能；执行中追加指令或加入原生队列；执行计划及 token 用量事件。
- 原生代码审查、队列管理和持续目标；特殊生命周期按原生事件处理，忽略旧轮次的结束事件。
- 技能发现/启停/选择、MCP 服务/工具/登录、插件目录/安装/卸载表单、原生项目编辑表单。
- 沙箱命令和主机交互 PTY；支持输入、尺寸同步和停止。Windows 沙箱命令流不支持时不自动提升执行权限。
- 命令会话级审批、额外目录/网络权限、MCP 表单/URL、客户端工具结果和旧版审批。
- 其他原生请求通过高级表单调用：附件引用、记忆、配置、Hooks、导入、实验功能、账户、实时、远程与环境等。

高级接口不等于完整官方交互：语音采集/播放面板、主机身份证明、完整 Git/PR、worktree、浏览器和调度器仍有独立工作。服务端限制会展示实际错误；不伪造支持。

验证：18 项后端测试，含全部可操作接口校验器编译、文件边界、审批和特殊任务状态。大型插件目录超过旧 16 MB 上限，现允许最大 128 MB 协议帧，并隐藏目录内嵌图像数据，新增 17 MB 回归测试。

真实测试覆盖 Plan、重命名、分叉、归档恢复、目标、队列、追加指令与 review/start。Electron 验证技能读取/重命名、沙箱命令、主机 PTY 输入/尺寸/停止、图片选择预览及原普通聊天/项目/桌宠/重启工作流。没有为了测试而改动用户的账户配置、插件安装和共享对象。
