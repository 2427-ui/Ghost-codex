# 0.2.1：玻璃材质与启动体验

历史记录：该版本的游戏视频及派生预览不属于当前公开分发内容。0.3.1 使用纯代码机械眼睛动画，原视频不在仓库或安装包内。

保留 C3 布局、白色基底、黑白灰配色、默认字号 18 和现有 Ghost 人设。

- 控件统一采用双层抛光边缘、弧形反射、透明内部和接触阴影；指针只更新局部高光，不运行持续的玻璃动画。正文与编辑器保持稳定底色。
- Ghost 增强银灰外壳、镜面边缘及虹膜层次；应用、桌宠、托盘及原生图标共用同一 SVG。
- 开场约 15.5 秒：用户提供的扩展版 HDD 视频以原速播放，保留扫描、窗口叠加、蓝色旋涡、HDD 标识及白光的原有节奏；约 12.75 秒白光后衔接银灰 Ghost 机械睁眼、短暂注视和首页落位。视频保留 2560×1440、30 fps，移除音轨、元数据和尾部黑场。
- 开场支持跳过按钮、Esc 和设置开关。减少动效时短淡入，关闭动效时直接进入；同一窗口刷新、托盘及桌宠恢复不重播。视频加载、播放失败或持续卡住时直接进入工作台，Codex 连接不阻塞开场结束。
- 连接状态独立显示 ONLINE / CONNECTING / OFFLINE。运行环轨缓慢运动、审批柔和脉冲，完成反馈只在新状态转换时播放；中断和错误使用静态提示。
- Windows 原生窗口的隐藏、最小化和恢复状态通过受限事件传到 renderer，隐藏时暂停装饰动画，恢复不重放旧完成反馈。
- 设置新增 startupAnimation，旧配置默认开启，并保留已有字号、人设和动效选择。本版未增加语音、识别模型、声音依赖或麦克风权限。

验证与限制见 [当前验证记录](VERIFICATION.md)，实际画面见 [截图索引](screenshots/README.md)。
