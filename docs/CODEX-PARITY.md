# 当前功能状态与后续工作

基线：Ghost Studio 0.3.1 + C3，Windows x64，2026-10-27。原 0.1.2 规划已移至 [历史归档](archive/CODEX-PARITY-0.1.2.md)，不再作为当前待办清单。

## 已提供的工作流

| 能力 | 当前实现与边界 |
| --- | --- |
| 普通聊天与本机历史 | 无需项目即可聊天；共享可枚举本机索引、分页与归档，查看不 resume，发送时才接续 |
| 项目 | 公开原生项目接口优先；创建/导入/编辑/排序/移除有高级入口，保留本地选择与旧版归属适配 |
| 会话管理 | 新建、重命名、归档/恢复、删除、分叉、回退、压缩、全文搜索与分组等接口；部分通过高级表单使用 |
| 输入与执行 | 执行/Plan、拖放文件、粘贴图片、@ 文件与选区引用、斜杠命令、新会话文字草稿、带附件 steer/队列、计划和用量 |
| 权限交互 | 命令、文件修改、问题、额外目录/网络、会话范围、MCP 表单/URL、客户端工具及旧版请求 |
| 工作区与 Git | 文件树、Monaco 多文件编辑、全文搜索与行定位、保存/冲突检查；Git 暂存、提交、恢复、分支、历史、推送和 gh 草稿 PR |
| 审查 | 专用范围表单，按原生退出审查事件完成；Diff 选行反馈引用至输入框，由用户发送 |
| 终端 | 沙箱非交互命令及明确确认的主机 PTY，支持输入、尺寸变化、停止与面板清理 |
| 扩展 | Skills、MCP、插件和应用等发现/管理接口，实际可用性取决于已配置服务与账户 |
| 视觉与桌宠 | C3 白色玻璃界面、银灰眼睛及原生图标、透明桌宠与会话共享、动效与字号偏好 |

协议快照共 172 个请求，168 个可操作入口。完整参数与证据见 [接口清单](CODEX-INTERFACES.md)。按钮存在不表示所有入口都已逐项实调，或已具备完整官方客户端体验。

## 仍需完成的工作

| 优先级 | 工作 | 当前缺口 |
| --- | --- | --- |
| P1 | 输入与富媒体 | 附件草稿跨重启恢复、附件历史的富媒体预览；现有文字草稿已持久化 |
| P1 | 专用任务与审查体验 | 目标的专用界面、复杂工具记录和更完整的结构化错误展示；队列/审查与选行反馈已有专用入口 |
| P1 | 完整 Git/PR 工作流 | 交互式冲突处理、合并/rebase、远端 PR 检查与评论；基础 Git 操作和创建草稿 PR 已提供，远端写入未实调 |
| P1 | 文件工作区 | 持续文件监听、文件管理、多根目录和外部编辑器入口；全文搜索、行定位和切回窗口刷新已提供 |
| P2 | 多会话并行与 worktree | 支持多个会话同时执行；缺少工作树生命周期、共享目录隔离、交接和合并工作流 |
| P2 | 通知与调度 | 目前有桌宠状态和托盘，尚无完整系统通知、定时任务与执行记录 |
| P2 | 浏览器与结果预览 | 主要打开外部链接，缺少内嵌浏览器和 PDF/文档/富媒体预览 |
| P2 | 语音、远程与云端 | 已有部分高级接口，缺少完整录音/播放、多机面板和跨端云历史 |
| P3 | 分发与稳定性 | 第二台电脑完整安装验证、长时间/大仓库/缩放压力验证、签名与自动更新 |

保持每项功能的真实执行、反馈、取消/失败、权限、持久化与重启行为可验证。不要把后端接口可调用视作所有官方服务自动兼容。
