# 0.1.2 — 本机历史与普通聊天

日期：2026-10-23。

- 接通当前 `CODEX_HOME` 中 App Server 可枚举的所有来源、所有模型提供商及归档会话，分页完整读取。
- 读取原生桌面端项目与普通聊天归属作为兼容映射；不写官方桌面状态文件或数据库，不读取认证文件。
- 会话正文仍归 Codex 管理。Studio 保存原始 ID 与元数据；外部创建 → Studio 继续 → 外部读取新回复已通过真实验证。
- 普通聊天不要求用户选择目录；内部目录自动创建，默认只读，主窗口和桌宠都可使用。
- 新建会话标题写入 App Server，两端可读取同一标题。
- 连接、主窗口重新获得焦点和手动操作均可刷新；可筛选全部、普通聊天、当前项目与归档。
- 查看历史不执行 resume；继续会话时才应用 Studio 当前模型、人设和权限。归档会话先只读查看。
- SQLite 自动迁移，保留旧版项目、会话引用、设置与草稿。

已完成 14 项后端测试、真实双客户端接续测试及 Electron 普通聊天/项目/桌宠/重启验收。跨进程同时执行同一会话、项目编辑双向同步、云端/远程记录不在本次完成范围。

下一步功能清单见 [CODEX-PARITY.md](CODEX-PARITY.md)。
