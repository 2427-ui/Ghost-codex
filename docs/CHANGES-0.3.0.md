# 0.3.0：输入、工作区与任务工作流

2026-10-26，保持 C3 白色玻璃风格与现有启动动画。

- 输入框支持拖入本机文件、粘贴 PNG/JPEG 图片、`@文件` 检索与引用，支持箭头键、Enter/Tab 和 Esc。单条消息最多 20 个附件、单文件 20 MB；图片在本机保存，未发送的粘贴图片不会自动上传。
- `/plan`、`/execute`、`/review`、`/search`、`/clear` 提供模式切换与工作区入口。文件和 Monaco 代码选区可以引用到输入框。普通聊天和每个项目的新会话文字草稿支持切换和重启恢复；附件列表尚不跨重启恢复。
- 文件区加入项目全文搜索，点击结果定位行；切回窗口刷新 Git、文件树和无未保存修改的文件。搜索为不区分大小写的字面量匹配，排除内部目录、常见生成目录、二进制与目录联接，最多扫描 10,000 个文件、返回 200 处结果，达到 5 秒预算时显示缩小范围提示。
- 变更区加入逐文件暂存、取消暂存、提交暂存内容、恢复未暂存修改、创建/切换分支、最近 30 条提交历史、推送 origin 和创建草稿 PR。工作区差异改为对比暂存区，暂存区仍对比 HEAD。路径以 Git literal pathspec 处理。仓库级操作要求打开仓库根目录；分支切换要求干净工作区。重命名与冲突的暂存处理仍使用终端。
- 恢复、推送、创建 PR 经过主进程原生确认。PR 使用用户已登录的 GitHub CLI（gh），先自行配置 origin 并推送分支。应用不会自动安装、登录 gh，也不会自动推送。Git 错误与取消均可见。
- 审查区可选择未提交变更、基准分支、指定提交或自定义指令。Diff 中选择行并写反馈后，可把路径、行号、选区与反馈加入输入框，再由用户发送。
- 按线程维护运行状态、服务端 turn ID、审批、流式缓存和错误，支持多个会话同时执行；停止按钮作用于当前会话。顶部任务条可切换运行中的会话，队列面板可查看、执行、删除原生队列条目。补充指令与排队支持已授权附件。
- 同一会话禁止重复启动；晚到的旧轮次完成事件不覆盖新任务。共享目录中的并行修改仍由用户协调，尚未增加 worktree 自动隔离、交接或合并。

验证：25 项后端测试，类型与生产构建，浏览器 UI 回归，离线原生工作流端到端测试。原生测试使用隔离 Git 仓库，实测草稿、粘贴/拖放、搜索、引用、反馈、暂存/取消暂存、恢复取消、提交与分支；未发起真实模型任务或远端推送/PR。多会话、队列和审查协议行为使用可控 RPC 测试，不视为账户实调证据。
