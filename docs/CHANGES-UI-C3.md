# C3 白色玻璃界面

日期：2026-10-23。

按用户选定的 C3 方案更新实际 Studio 界面：白色主背景、雾灰侧栏、浅灰网格与双轨道、银灰机械大眼睛、透明玻璃控件。

- `src/renderer/src/theme.css` 集中维护浅色语义色、玻璃边缘、高光、投影、交互状态及各界面的材质。基础样式、功能中心和桌宠样式使用同一组浅色变量。
- Ghost 的 SVG 保留原有轮廓、眼睛比例、右下白色反光、眨眼、视线跟随和任务状态，更新银灰金属渐变与细密环纹。每个实例的渐变和裁剪 ID 独立。
- 聊天状态降低背景网格存在感；设置、审批、功能中心、附件、Monaco 编辑器与 xterm 终端配套使用浅色。终端 ANSI 与代码差异保留必要的语义色。
- 桌宠保留透明窗口、拖动、会话展开与恢复工作台；窗口初始背景改成白色。
- 不修改账户、协议、项目数据或任务执行逻辑。

## 验证

- `npm test`：18/18 通过。首次沙箱运行的临时目录链接与 Git 写入限制，已通过正常权限重跑确认。
- 生产 renderer 的本地浏览器检查通过：首页 1440×940 与 1366×768、Markdown/表格、附件、发送、编辑器、设置、功能中心、终端、审批、视线跟随、全部任务状态和系统减少动效；没有页面异常。
- 原生 Electron 与打包后的 GhostStudio.exe 均通过：首页、设置、收起桌宠、展开桌宠对话及恢复工作台；没有页面异常。
- 界面验证使用独立测试目录与本地模拟数据，不调用用户账户或发起真实任务。

截图及机器可读记录保存在 `output/ui-c3/`。`packaged-home.png` 为打包程序的实际界面截图；`verification.json`、`native-verification.json` 与 `packaged-verification.json` 保存验证结果。

## 启动

`dist/win-unpacked/GhostStudio.exe` 已重新打包。项目根目录 `启动Ghost.cmd` 会优先启动该构建。

## 原生图标补齐

任务栏、托盘与 EXE 图标统一为 C3 银灰大眼睛。`scripts/create-icon.mjs` 直接渲染界面使用的 SVG，生成透明 PNG 及包含 16、20、24、32、40、48、64、128、256 像素的 ICO；窗口显式指定该 ICO，托盘继续使用对应 PNG。

已重新构建并打包，验证 EXE 包含全部九种尺寸，asar 中的 ICO/PNG 与源资源逐字节一致。通过 Windows WM_GETICON 提取实际运行窗口图标及原生关联图标提取，确认均为非空黑白灰图像。验证记录：`output/ui-c3/icon-verification.json`。

更新正在运行的实例时，应从托盘选择“退出”，再使用项目启动器启动；窗口关闭按钮会收起为桌宠。
